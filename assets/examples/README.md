# Computational chemistry examples

These files accompany the Computational Chemistry Notes pages.

- `rdkit/rdkit_conformers.py`: ETKDGv3 conformer generation, MMFF94 optimization, and SDF export.
- `xtb/acetophenone.xyz`: XYZ input for xTB examples.
- `gaussian/acetone-opt-freq.gjf`: Gaussian optimization and frequency input.
- `pyscf/water_opt.py`: PySCF DFT and geomeTRIC optimization example.
- `psi4/water-dimer-sapt.dat`: Psi4 SAPT0 input.
- `orca/li-nh3-eda.inp`: ORCA 6.1 EDA-NOCV input.
- `cube/pyscf_cube.py`: PySCF electron-density, ESP, and HOMO cube generation.
- `nciplot/water-dimer.nci`: NCIplot input template.
- `py3dmol/view_rdkit.py`: RDKit to py3Dmol visualization example.
- `cheminformatics/rdkit_features.py`: identifiers, descriptors, fingerprints, and SMARTS matching.
- `data-analysis/regularized_regression.py`: standardized Elastic Net regression with a held-out test set.
- `steric/README.md`: DBSTEP command templates for Sterimol and percent buried volume.

These are educational starting points rather than universal production protocols.
Check software versions, licenses, charge, spin, method, basis set, solvent,
convergence criteria, and units for each chemical problem.
