Terms and Definitions

1. A–F

AFIR
人工力誘起反応法。反応物間または分子内に人工力を加え、反応経路候補を系統的に探索する手法。 関連章
基底関数系 / Basis set
分子軌道を展開する既知関数の集合。計算精度と計算量を左右する。 関連章
Boltzmann weight
各配座の相対自由エネルギーと温度から求める統計的な存在比。 関連章
Canonical SMILES
同一構造に対して一意になるよう特定実装で正規化したSMILES。異なる実装間での同一性は保証されない。 関連章
配座 / Conformer
結合を切らずに主として単結合回転で相互変換できる三次元構造。 関連章
Cube
原子座標と、規則的な三次元格子上のスカラー値を格納するファイル形式。 関連章
DFT
電子密度を基本変数として多電子系を扱う密度汎関数理論。 関連章
Dual descriptor
電子付加と電子除去に対する局所応答の差で、求電子・求核反応性の傾向を表す概念DFT記述子。 関連章
EDA
定義した参照状態に基づき、相互作用エネルギーを静電、Pauli反発、軌道相互作用などへ分解する解析。 関連章
ESP
原子核と電子が空間中の点に作る静電ポテンシャル。評価位置または写像面を明示する。 関連章
ETKDG
実験由来のねじれ角知識を距離幾何法へ組み込んだRDKitの配座生成法。 関連章
Fingerprint
分子部分構造や局所環境の有無をビット列または数値ベクトルで表した記述子。 関連章
Fukui function
電子数の変化に対する電子密度の局所応答を表す概念DFT量。 関連章

2. G–M

Gasteiger charge
結合関係と原子種から反復的に推定する経験的部分電荷。量子化学的電荷とは異なる。 関連章
GRRM
反応経路自動探索のためのプログラム群。ADDF、AFIRなどの探索法を備える。 関連章
IGM / IGMH
密度勾配の打ち消しを利用して相互作用領域を可視化する手法。IGMHはHirshfeld分割を用いる。 関連章
InChIKey
InChIから生成される固定長文字列。検索に便利だが、元構造へ復号できない。 関連章
IRC
遷移状態から反応物側と生成物側へ辿る固有反応座標。 関連章
Isovalue
スカラー場の等値面を描くときに固定する値。面の大きさと解釈はこの値に依存する。 関連章
LASSO
L1罰則により係数を縮小し、一部を厳密にゼロにできる正則化回帰。 関連章
MC-AFIR
複数成分間へ人工力を適用し、多様な会合・反応経路を探索するAFIR法。 関連章
MMFF
主に有機分子向けのMerck Molecular Force Field。配座の初期最適化などに用いる。 関連章
分子軌道 / Molecular orbital
一電子関数として表現される軌道。描画色は通常、電荷ではなく位相を表す。 関連章

3. N–S

NCI
低電子密度かつ低換算密度勾配の領域から非共有結合相互作用を調べる解析。相互作用エネルギーそのものではない。 関連章
NCIplot
NCI解析用の格子データと可視化ファイルを生成するプログラム。 関連章
PCA
分散が大きい直交方向へデータを射影する主成分分析。前処理は検証分割の内側で学習する。 関連章
RDG
電子密度とその勾配から作る無次元の換算密度勾配。NCI解析の基本量。 関連章
RMSD
原子対応を定め、最適重ね合わせ後に求める二構造間の二乗平均平方根偏差。 関連章
SAPT
分子間相互作用を静電、交換、誘起、分散などへ摂動論的に分解する方法。 関連章
SC-AFIR
単一成分内へ人工力を適用し、異性化や解離経路を探索するAFIR法。 関連章
SCF
入力密度から得た軌道が新しい密度を作り、所定の基準まで自己無撞着に反復する手続き。 関連章
SHAP
予測値と基準値との差を特徴量寄与へ加法的に配分する説明手法。因果効果を直接示すものではない。 関連章
SMILES
原子、結合、分岐、環などを文字列で表す分子表記。三次元配座は通常含まない。 関連章
Steric map
基準座標系から見た立体的な混雑度を二次元面へ投影した地図。 関連章
Sterimol
定義した主軸に沿う置換基長Lと、軸に垂直な最小幅B1・最大幅B5。 関連章

4. T–Z・記号

遷移状態 / Transition state
ポテンシャルエネルギー面上の一次鞍点。通常、一つの虚振動と反応経路への接続を確認する。 関連章
UFF
元素被覆範囲の広いUniversal Force Field。適用可能性と電荷状態を確認して使う。 関連章
Voxel
三次元格子を構成する一つの体積要素。場を機械学習へ渡すときの基本単位。 関連章
波動関数 / Wavefunction
量子状態を表す関数。解析用ファイルには軌道係数や基底関数情報などが保存される。 関連章
%Vbur
指定球内で原子のvan der Waals体積が占める割合。中心、半径、原子半径系に依存する。 関連章
ΔΔG‡
競合する経路間の活性化自由エネルギー差。比との変換では温度と符号規約を固定する。 関連章
