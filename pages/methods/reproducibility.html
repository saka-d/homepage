計算・解析の再現可能性

入力、計算条件、三次元場、データ分割、可視化設定を、結果と同じ単位で保存するための実践指針です。

この章の内容

  1. 推奨ディレクトリ構成
  2. 命名とmetadata
  3. 電子状態計算
  4. Cubeと実空間解析
  5. 機械学習
  6. 公開前チェック
  7. サイトの保守

1. 推奨ディレクトリ構成

project/
  inputs/          # source structures and raw tables
  conformers/      # generated ensembles and energies
  quantum/         # input, log, chk/fchk, gbw
  fields/          # cube, grid metadata, fragment definitions
  features/        # descriptor tables and schemas
  models/          # splits, pipelines, parameters, metrics
  figures/         # scripts and exported figures
  environment/     # versions and installation records

2. 命名とmetadata

sample ID、配座ID、電荷、多重度、method、basis、溶媒、計算段階を機械的に結合し、表示用名称と分離します。CSV/JSONには単位、欠損値規則、原子index規則、生成スクリプトのcommitを保存します。

3. 電子状態計算

  • softwareとrevision、計算資源
  • geometry、charge、multiplicity
  • method、basis、ECP、dispersion、grid
  • SCF・最適化・振動数の収束
  • 温度、圧力、標準状態、熱補正
  • 再計算・再開時のcheckpoint対応

4. Cubeと実空間解析

物理量、原点、三本のaxis vector、shape、単位、spacing、fragment、isovalue、カラーレンジを保存します。差分やpixel-wise modelでは、grid一致をプログラムで検証します。

5. 機械学習

元データ、固定test set、group ID、前処理pipeline、乱数シード、hyperparameter探索範囲、評価指標を保存します。標準化・PCA・特徴選択はvalidation foldの外でfitしません。

6. 公開前チェック

  1. 新しい環境で生成スクリプトを実行できる。
  2. 原データから主要表・図まで追跡できる。
  3. 手作業の変更をREADMEへ記録した。
  4. ライセンス・引用・公開可否を確認した。
  5. 機密構造や個人情報を除外した。
  6. Methodsページの対象versionと最終確認日を更新した。

7. このサイトの再生成と保守

本文、日英ページ、計算例への接続、検索索引、構造化データはスクリプトから再生成します。生成物だけを直接直すと次回の実行で失われるため、対応する scripts/i18n/ または後処理スクリプトを修正します。

npm run i18n:generate
npm run i18n:markup
npm run verify:site
  • i18n:generate: 日英ページ、計算例、章間リンク、検索索引、JSON-LDを再生成。
  • i18n:check: 日英ページ数、翻訳漏れ、章・コード例の対応を検査。
  • site:validate: ローカルリンク、重複ID、canonical、JSON-LD、検索索引、計算メタデータを検査。
計算例の来歴

各 assets/calculations/*/metadata.json に分子、手法、ソフトウェアバージョン、乱数シードまたは格子条件、検証値、教育用例である旨を保存します。
